# MESO(MakE SOftware)

대원고 급식, 개인 시간표, 공지, D-Day와 학생 활동을 제공하는 정적 웹사이트입니다.

## 주요 기능

- 활동 유형별 탐색 및 브라우저 북마크
- 카드뉴스 뷰어
- 매일 바뀌는 AI·컴퓨터 1분 퀴즈와 연속 참여 기록
- 이진수 해독 미니게임
- NEIS 오늘 급식 조회
- 개인 시간표 작성 및 오늘 수업 요약
- 학년별 1~8반 NEIS 과목 자동완성
- Google Sheets 기반 공지, 일정, 학교정보 관리

## Google Sheets 관리자 설정

1. Google 스프레드시트를 새로 만들고 `공지사항`, `일정`, `학교정보` 탭을 생성합니다.
2. 시트를 `링크가 있는 모든 사용자: 뷰어`로 공유합니다.
3. 스프레드시트 주소의 `/d/`와 `/edit` 사이에 있는 ID를 복사합니다.
4. `config.js`의 `googleSheetId`에 복사한 ID를 입력합니다.

### 공지사항 탭

| 제목 | 내용 | 등록일 | 중요 | 링크 | 공개 |
|---|---|---|---|---|---|
| 7월 모의고사 안내 | 8시 10분까지 입실 | 2026-07-15 | 중요 |  | 공개 |

`중요` 열에 `중요`를 입력하면 상단에 먼저 표시됩니다. `공개` 열에 `비공개`를 입력하면 사이트에 표시되지 않습니다.

### 일정 탭

| 일정명 | 날짜 | 종류 | 공개 |
|---|---|---|---|
| 2027학년도 대학수학능력시험 | 2026-11-19 | 수능 | 공개 |

날짜를 기준으로 `D-100`, `D-DAY`, `D+1` 형식이 자동 계산됩니다.

### 학교정보 탭

| 항목 | 제목 | 내용 | 링크 | 링크 문구 | 공개 |
|---|---|---|---|---|---|
| OFFICIAL | 학교 공식 홈페이지 | 학교의 공식 정보를 확인하세요. | https://daewon.dge.hs.kr | 홈페이지 열기 | 공개 |

시트 ID가 비어 있거나 연결에 실패하면 사이트에는 기본 샘플 데이터가 표시됩니다.

## 실행

별도 빌드 과정은 없습니다. 프로젝트 폴더에서 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

## 파일 구조

```text
index.html   페이지 구조
styles.css   전체 디자인 및 반응형 스타일
script.js    콘텐츠, API, 저장 및 상호작용
config.js    Google Sheets 연결 설정
images/      이미지 리소스
```

활동 샘플 콘텐츠는 `script.js`의 `activities` 배열에서 수정할 수 있습니다.
