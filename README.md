`중요` 열에 `중요`를 입력하면 먼저표시 `공개` 열에 `비공개`를 입력하면 사이트에 표시안댐

```bash
python -m http.server 8000
```

## 파일 구조

```text
index.html   페이지 구조
styles.css   전체 디자인 및 반응형 스타일
script.js    콘텐츠, API, 저장 및 상호작용
config.js    Google Sheets 연결 설정
images/      이미지 리소스
```
